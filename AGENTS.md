# tasty-coach

- Purpose — Helps review a Tastytrade account, scan opportunities, and monitor positions.
- Setup — Install `requirements.txt`, create a private `.env`, then use `python main.py --test-connection`.
- Safety — Never place a real trade without the user's explicit approval.
- Testing — Use the test or paper environment before trying account-connected changes.
- Privacy — Never commit OAuth details, account numbers, logs, or trade records.
- Details — Read `CLAUDE.md` before changing trading or account behaviour.
